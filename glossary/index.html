Glossary

Plain-language definitions of the terms used in these essays. In an essay, hover over or tap a dotted-underlined word to see its definition.

Attention
A mechanism that lets each token look at every other token and work out how much each one matters for understanding it. The weights are computed fresh for each input, using parameters learned in training.
Attention head
One of several attention calculations that run side by side in a layer, each with its own learned parameters.
Attention sink
A token, usually at the start of the text, that receives a lot of attention even though it carries little useful meaning.
Base model
A language model that has been pretrained to continue text but not yet trained to follow instructions or hold a conversation.
Byte-pair encoding (BPE)
The most common way to build a tokenizer’s vocabulary: start from single characters (or bytes) and repeatedly merge the most frequent neighboring pair into a new token.
Compute
The total amount of calculation spent on a task, such as training a model.
Context window
The maximum number of tokens a model can take into account at once, covering both your input and its reply.
Embedding
A list of numbers (a vector) that represents a token. Tokens with related meanings end up with similar embeddings.
Emergent ability
A skill reported as absent in smaller models but present in larger ones. Researchers disagree about how many such jumps are real and how many come from the way a test is scored.
Fine-tuning
Further training of a pretrained model on a smaller, focused dataset to adapt it to a particular task or style.
GPU
Graphics processing unit. A chip built to do many simple calculations at once, originally for graphics, now the workhorse of AI training.
Loss
The number training tries to make smaller. For a language model it measures how surprised the model is by the token that actually comes next.
Mask (causal)
The step that hides later tokens, so a model trained to predict the next token cannot look ahead.
Parameters
The numbers inside a model that are adjusted during training. “175 billion parameters” means 175 billion of these adjustable weights.
Power law
A relationship in which multiplying one quantity by a fixed amount always multiplies another by a fixed amount.
Pretraining
The first, most expensive stage of training, where a model learns general patterns from a huge amount of text, usually by predicting missing or next words.
Prompt
The text you give a model as input. A model’s output is its continuation of, or response to, the prompt.
Query, key and value
Three lists of numbers an attention head makes from each token. Queries are compared with keys to set the weights, and the weights decide how much of each value is passed along.
Reward model
A model trained on people’s comparisons to score replies by how likely people are to prefer them.
RLHF
Reinforcement learning from human feedback. People compare or rank model responses, and the model is tuned toward the responses they prefer.
Scaling laws
Empirical rules showing that a model’s error falls smoothly and predictably as you increase its size, training data and compute.
Softmax
A function that turns a list of scores into positive weights that add up to 1, exaggerating the gap between large and small scores.
Sycophancy
A tendency to tell people what they want to hear, such as agreeing with a mistaken view, instead of what is accurate.
Token
The unit of text a model reads and writes: usually a word or a piece of a word. GPT-2’s tokenizer splits “unbelievable” into “un”, “bel”, “iev” and “able”.
Tokenizer
The program that splits text into tokens and turns each one into an ID number before a model sees it, and turns IDs back into text afterward.
Transformer
The neural-network architecture introduced in “Attention Is All You Need” (2017). It is built from stacked layers of attention and small feed-forward networks, with no recurrence.
Vocabulary
The fixed list of tokens a tokenizer can produce. Each entry has an ID number. Typical sizes range from about 50,000 to a few hundred thousand.
